SSRP Studio Dinamis

Alat canggih untuk merender Screenshot Roleplay (SSRP) dengan resolusi Ultra HD langsung di dalam Discord.

Cara Penggunaan: /ssrp

  • Ketik perintah /ssrp di channel mana pun. Bot akan membuat Thread khusus agar obrolan server tidak terganggu.
  • Pilih mode: Manual Mode (ketik teks RP langsung di panel) atau Otomatis (upload file chatlog.txt).
  • Untuk mode otomatis, gunakan Lua script chatlogs_ssrp.lua di dalam game (ketik /cssrp) untuk mengekstrak chatlog tanpa UI server. Tersedia juga perintah /chatlogs untuk membersihkan file .txt.
  • Setelah teks dimasukkan, klik tombol Kirim Gambar dan upload foto mentah SS Anda.
  • Gunakan tombol panah untuk geser (pan) kamera dan zoom, ubah ukuran Font (12, 13, 14), lalu klik Finishing (HD).
